---
title: Authentication
description: Authentication is optional in MAD. An implementation may use any token system that generates a token for identity.
status: draft
---

MAD treats the authentication system as optional when constructing an RTW network.

The MAD network does not natively persist data into databases or filesystems. It is designed as a distributed machine network. The network can be tokenized and limited to the system that issues the token and how this is mapped to the user or network resource. Any token system that generates a token for identity can be used.

Once a user has been registered in an implementation, they may participate in RTW and become members of services by getting access to ghosts.

Access can be revoked. Morphing a ghost against a secondary service grants read access that the owner can withdraw. Implementations may also revoke tokens.
