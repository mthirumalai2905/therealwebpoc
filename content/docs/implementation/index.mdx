The Real Time Web is a network architecture. It is not a single product. Compatible tools, services, and commercial products can be built on it. Anyone can develop an implementation of MAD or RTW.

Real Time Web is a network concept and architecture. Morph Space is a commercial platform and a known implementation that lets people and organizations join and use a live network built on MAD. Synx is a known toolchain for configuring, securing, and operating services. Those two are not the architecture, and they are not the only possible implementations.

This site explains the model. It does not onboard anyone, collect leads, or send readers to a signup.
