The Real Time Web is a network architecture. Compatible tools and services can be built on it.

Morph Space is a known marketplace implementation. Synx is a known toolchain for configuring and operating services. Those two are not the architecture, and they are not the only possible implementations.

## What is written

The known implementation named in the source is **Morph Space**. That network uses tools from **Synx**. **Skalle** is listed here as another party planning an implementation.
